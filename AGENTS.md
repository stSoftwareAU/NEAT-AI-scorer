# AGENTS.md

- Workspace member: **`rust_scorer`** (CLI + `float_scan_bench`). **`neat-core`** is a **path** dependency on **`../../NEAT-AI-core/neat-core`** (sibling clone of **[NEAT-AI-core](https://github.com/stSoftwareAU/NEAT-AI-core)**). Forward-only scoring uses **`neat_core::training_bin_stream::for_each_read_chunk`** only (native pipelined I/O; wasm32 sequential chunks — one API, no mmap / no alternate scan modes).
- Keep the **positional** CLI contract (`<creature.json> <data_dir>`) stable.
- **GPU plumbing (Issue #80, #83, #180):** `--gpu <auto|on|off>` (and `NEAT_SCORER_GPU=…`, CLI wins) selects between the CPU pipeline (emits `gpuBackend: "cpu-fallback"`) and `wgpu` adapter detection. **`auto` is the default since #83** (multi-creature directory path only; single-creature stays CPU): it falls back silently to CPU when no GPU is found, when the cost is non-MSE, or when a creature exceeds the GPU shader cap. `off` skips `wgpu` entirely; `on` exits non-zero if a GPU cannot host the run. The `forward_mse_batched` shader caps at **256 neurons** per creature (`MAX_NEURONS_PER_CREATURE`); real evolved creatures routinely exceed this, so directory-mode `auto` runs a CPU-only pre-flight (`multi_score::gpu_directory_compatible`, #180) **before** creating any GPU device — an unhostable set never spins up a `wgpu` context, guaranteeing a clean CPU fallback (valid JSON, exit 0). The new `gpuBackend` JSON field never replaces or shifts the existing keys — `trainingReadBackend` and the rest stay as-is.
- **Cost selector (Issues #120, #121, #134):** `--cost <NAME>` picks the loss function. Accepts the seven TypeScript `BUILT_IN_COST_NAMES` values (`MSE` (default), `MAE`, `MAPE`, `MSLE`, `HINGE`, `CROSS_ENTROPY`, `CATEGORICAL_ERROR`); unknown values hard-error via clap. No env-var override. All seven now dispatch through `accumulate_cost_sum` — Issue #134 unblocked `CATEGORICAL_ERROR` after `categorical_error_sum_batch_packed` landed via `NEAT-AI-core#88`. The GPU `forward_mse_batched` kernel is MSE-only — non-MSE costs run on the CPU pipeline under `--gpu auto` and hard-error under `--gpu on`. The resolved name is echoed back as the `costName` JSON field. See the README "Cost function selector" section for per-cost examples.
- Local gate: run **`./quality.sh`** before commit/PR (shellcheck, optional `cargo upgrade`, **cargo-deny**, `fmt --check`, clippy, check, build, test, `doc` with `RUSTDOCFLAGS=-D warnings`, release build).
- CI (`.github/workflows/ci.yml`): `fmt`, **cargo-deny**, `clippy` (`filter_next` / `collapsible_if`), `check`, `build`, `test`, **rustdoc**, plus **shellcheck** on `*.sh`; **validation** (required files + `cargo metadata`); **codespell**; PR-only **security** (`cargo audit` + dependency review). Dependency bumps happen per-PR via **`bump-deps.sh`** (Issue #105) — there is no scheduled bump workflow.
- Extra `clippy::*` allows live in workspace `Cargo.toml` so `-D warnings` is viable on this imported code; align with Discovery pedantic rules gradually if you want stricter parity.
