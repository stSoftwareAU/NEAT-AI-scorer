# AGENTS.md

- Workspace member: **`rust_scorer`** (CLI + `float_scan_bench`). **`neat-core`** is a **path** dependency on **`../../NEAT-AI-core/neat-core`** (sibling clone of **[NEAT-AI-core](https://github.com/stSoftwareAU/NEAT-AI-core)**). Forward-only scoring uses **`neat_core::training_bin_stream::for_each_read_chunk`** only (native pipelined I/O; wasm32 sequential chunks — one API, no mmap / no alternate scan modes).
- Keep the **positional** CLI contract (`<creature.json> <data_dir>`) stable.
- **GPU plumbing (Issue #80, #83, #180, #317, #319):** `--gpu <auto|on|off>` (and `NEAT_SCORER_GPU=…`, CLI wins) selects between the CPU pipeline (emits `gpuBackend: "cpu-fallback"`) and `wgpu` adapter detection. **`auto` is the default since #83** (multi-creature directory path only; single-creature stays CPU): it falls back to CPU when no GPU is found, when the cost is not GPU-supported (anything other than MSE/RMSE/MAE — #316), when pre-flight finds an unhostable set (#180), or when the creature directory topology is **Mixed** or **ScratchOnly** (#317 — GRQ production full-corpus A/B on M4: CPU ~3× faster than scratch GPU even with dual-kernel + 32 MiB reads). **`AllPrivate`** pools (≤256 total neurons per creature, synthetic bench shape) still use GPU under `auto`. `off` skips `wgpu` entirely; `on` exits non-zero if a GPU cannot host the run (or forces GPU for debug). Dual-kernel directory scoring (#317) dispatches `forward_mse_batched` and `forward_mse_scratch` in one I/O pass when a pool mixes small and large creatures. The `forward_mse_batched` shader caps at **256 neurons** per creature (`MAX_NEURONS_PER_CREATURE`, fixed `private` activation array — **inputs count**); creatures above it route to **`forward_mse_scratch`** (#182). Large-record corpora (≥8000 B/record, GRQ ≈9848 B) default to **32 MiB** read chunks when `NEAT_SCORER_READ_BYTES` is unset (`read_tuning`). Directory-mode `auto` runs CPU-only pre-flight (`multi_score::gpu_directory_compatible`, #180) and topology probe (`gpu_directory_topology_for_dir`) **before** creating any GPU device. **Issue #319:** scratch/mixed directory GPU runs clamp `inflight_chunks` to **1** (synchronous dispatches) — pipelined `inflight=2` with 32 MiB reads SIGSEGV'd on Metal across `.bin` file boundaries; all-private benches may still pipeline. Since **#305** both kernels inline every **point-wise** squash (`SquashType` 0..=31), and since **#312** they also reduce MINIMUM/MAXIMUM/IF (32..=34) inline and host **constant neurons** — the real GRQ creature is GPU-hostable under `--gpu on`, but **`auto` picks CPU** for scratch topology on M4/M5. Only HYPOT/HYPOTv2/MEAN (35..=37) force pre-flight CPU fallback via `squash_supported`. Topology fallback prints one stderr note under `auto` (mirror #205). The `gpuBackend` JSON field never replaces existing keys.
- **Cost selector (Issues #120, #121, #134, #316, #338):** `--cost <NAME>` picks the loss function. Accepts `MSE` (default), `RMSE`, `MAE`, `MAPE`, `MSLE`, `HINGE`, `CROSS_ENTROPY`, `CATEGORICAL_ERROR`; unknown values hard-error via clap. No env-var override. `RMSE` (#338) reuses MSE's `mse_sum_batch_packed` accumulation and applies a single host-side `sqrt` at finalisation via the shared `CostKind::finalise_mean` helper (called at every CPU finalisation site so the `sqrt` cannot drift between paths); its upstream TypeScript `BUILT_IN_COST_NAMES` entry is tracked in the upstream-sync sub-issue. All costs dispatch through `accumulate_cost_sum` — Issue #134 unblocked `CATEGORICAL_ERROR` after `categorical_error_sum_batch_packed` landed via `NEAT-AI-core#88`. The GPU `forward_mse_batched` / `forward_mse_scratch` kernels serve **MSE, RMSE and MAE** on one shared forward pass, selecting the per-record loss via the shader `cost_kind` header field (`CostKind::gpu_error_code`): MSE/RMSE accumulate squared error (RMSE only adds a host-side `sqrt`, so it is GPU-supported at MSE speed); MAE accumulates absolute error (Issue #316), GPU-hosted on both the private-array and > 256-neuron scratch kernels. Every other (non-MSE/RMSE/MAE) cost runs on the CPU pipeline under `--gpu auto` and hard-errors under `--gpu on`. The resolved name is echoed back as the `costName` JSON field. See the README "Cost function selector" section for per-cost examples.
